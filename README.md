# R-R Prototype
Experimental playground built with **Laravel 11**, **React**, **Inertia**, **TypeScript**, **Tailwind CSS** and **shadcn/ui**.

This project is a visual and technical sandboz for building a dynamic fashion e-commerce interface.
The goal is to explore reusable UI components, animated product pages, editorial layouts and future interactive experiences for a clothing / fashion store.

## Current Stack
Herramientas de momento:
- Laravel + React
- Shadcn
- Inertia.js
- TypeScript
- Tailwind CSS

## Planned Tools

- Storybook
- Motion
- GSAP
- Three.js

## Purpose

This repository works as a playground for testing:

- reusable UI components
- fashion e-commerce layouts
- animated landing pages
- product cards and product detail pages
- editorial sections
- future 3D or scroll-based interactions

## Local Development

Start the Laravel server:

bash
php artisan serve
